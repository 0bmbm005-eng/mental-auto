現在:

- 直近3件の日次ログを古い日付から順に読み込む
- AIなしでも既存機能は利用可能で、通常の `--advice` はログ内容と振り返り質問を表示する
- 生成結果は JSON として stdout に出力し、元ログには書き込まない
- `--preview-advice` は通常送信と共通の入力生成・リクエスト構築を使い、通信・ファイル変更なしで送信予定のJSONのみをstdoutに表示する。利用例と注意点は README、処理順と責務は docs/design.md を参照

- `--sanitize-advice` で送信本文のコピーだけに共通のメール・キー・パスマスクを適用できる。長文・空白・改行・日付・順序・元ログは保持する。`sanitized: true` は限定的なマスク適用済みを意味し、完全な匿名化ではない。未指定時は従来どおり `false`。`--safe-share` の整形・省略は維持する
