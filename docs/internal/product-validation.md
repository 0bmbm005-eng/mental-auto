# mental-auto Product Validation

## 現在の位置づけ

`mental-auto` は、日々の短い心理記録を日付別 Markdown として蓄積し、長期的な自己変化の観察と、将来の AI 分析を試すために使用している個人用の実験基盤である。一般利用者に対する比較優位や、AI 分析の効率改善はまだ検証されていない。

## 明確になった事実

- JST 日付で `logs/YYYY-MM-DD.md` に短い記録を保存する CLI である
- `--date` による日付指定ができる
- 保存場所とファイル名を一定形式に揃えられる
- 利用者本人が日々の記録に実際に使用している
- 蓄積された記録を後から振り返っている
- 現在の `mental-auto` 自体には高度な AI 分析機能はない
- 「短文でよい」という心理的な始めやすさは、ツール固有の機能ではなく運用ルールによる部分が大きい

## 残っている仮説

- 日付別 Markdown 形式は将来の AI 分析に適している
- 一定形式の蓄積は、他の記録方法より分析準備を楽にする
- `mental-auto` は日次記録の継続を助ける
- 他の利用者にも同じ価値がある

## 矛盾または弱い部分

- 「AI 分析を効率化する」という主張に測定結果がない
- Apple メモ、Obsidian、手動 Markdown より優れているという比較根拠がない
- 失敗防止や継続率改善を示す具体例や測定値がない
- `mental-auto` 固有の価値と、短文記録ルールや毎日の習慣の価値が混ざりやすい
- 月次分析の対象ファイル選択は現在も人間が確認する必要がある

## 次に検証すること

最初の検証は、小さく実行可能なものから始める。

1. 直近 1 か月分のログを使い、AI に月次分析を依頼する
2. 分析前に必要だった作業を記録する
3. 対象ファイルを探す時間、選択時の迷い、追加説明の量を記録する
4. 現在の Markdown 形式で不足した情報を記録する
5. 分析結果が実際の自己理解や次の行動に役立ったかを確認する

## 現時点で使ってよい表現

- 日付別 Markdown として短い記録をローカルに保存する CLI
- 毎日の記録を一定形式で蓄積するために使用している
- 将来の振り返りや AI 分析を試すための個人用実験基盤

## 現時点では使わない表現

- AI 分析を効率化するツール
- 他のメモアプリより継続しやすい
- 記録漏れや日付ミスを防ぐ
- 誰でもメンタルを改善できる
- Apple メモや Obsidian より優れている
